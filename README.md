## Pregunta Final

### ¿Cómo facilita GitHub el trabajo colaborativo en un proyecto de desarrollo de software?

GitHub facilita el trabajo colaborativo al actuar como una plataforma centralizada que combina el control de versiones de Git con herramientas de gestión de proyectos:

* **Control de versiones y ramas paralelas:** Permite que múltiples desarrolladores trabajen simultáneamente en diferentes funcionalidades a través de ramas independientes, evitando sobreescribir el trabajo de los demás.
* **Trazabilidad y transparencia (Commits e Issues):** Mantiene un historial claro de quién realizó cada cambio y permite organizar tareas específicas asignando responsables claros a cada requerimiento.
* **Control de calidad mediante Pull Requests:** Obliga a que los cambios sean revisados y comentados por otros integrantes antes de integrarse a la rama principal (`main`), asegurando la calidad del código y la detección temprana de errores.
