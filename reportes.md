# Reportes de AppConnect

## Descripción
Sección para generar y consultar reportes sobre el uso del sistema, usuarios y aplicaciones registradas.

## Información registrada
* **Tipo de reporte:** Categoria del informe.
* **Fecha y hora:** Momento de generación.
* **Usuario:** Quien solicitó el reporte.
* **Resumen:** Datos u operaciones realizadas.

## Funcionamiento
1. Seleccionar el tipo de reporte.
2. Aplicar filtros (fechas o categorías).
3. Visualizar en pantalla o descargar el archivo.

## Objetivo
Ofrecer una visión clara del estado del sistema para facilitar la toma de decisiones.
